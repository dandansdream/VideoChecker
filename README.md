# 视频完整性检测工具（VideoChecker）

PS：这个主要是仓鼠患者使用0.0

> 英文版文档见 [README_En.md](README_En.md)。

检测磁盘/文件夹中的视频文件是否完整（识别下载中断、录制未结束等造成的截断与损坏），
列出结果供手动勾选删除（走系统回收站，可随时还原）。

## 使用

双击 `VideoChecker.exe` 即可，无需安装。

1. 选择检测位置（磁盘下拉框 / 选择文件夹 / 手输路径）
2. 勾选要检测的视频格式
3. 按需调整"扫描线程"（1~32，默认 8；机械硬盘建议 4~8，SSD 可调高）
4. 点"开始扫描"，等待完成
5. 在结果表中筛选、勾选，点"删除所选（移入回收站）"

提示：
- 首次启动需 3~5 秒（单文件自解压）
- 扫描为多线程并行检测，线程数可随时在界面上修改
- 删除只移入回收站，不直接销毁
- 双击结果行可打开文件所在位置

## 检测能力

判定分三级：
- **✔ 完整**：容器结构规范完整
- **⚠ 结构异常(可播放)**：尾部截断、缺索引、尾部垃圾字节等——PotPlayer/VLC 等播放器通常能正常播放，不建议删除
- **✖ 损坏(建议删除)**：缺 moov/moof 索引、结构严重损坏、0 字节——大概率无法播放

| 格式 | 检测深度 |
|------|----------|
| MP4 / MOV / M4V / 3GP | 深度：box 结构遍历 + moov/moof 索引校验 |
| MKV / WebM | 深度：EBML 结构遍历 |
| AVI | 深度：RIFF 结构遍历 + idx1 索引校验 |
| FLV | 深度：tag 链遍历 + PreviousTagSize 校验 |
| TS / MTS / M2TS | 包对齐 + 首尾同步字节 |
| WMV / MPG / VOB / RM(RMVB) | 仅文件头校验（标"结构异常"，无法深度校验） |

全盘扫描自动跳过 Windows、Program Files、$RECYCLE.BIN 等系统目录。

## 源码说明

- `detector.py` —— 检测核心：各格式容器结构校验、磁盘枚举、回收站删除
- `video_checker_gui.py` —— 原生桌面界面（Tkinter 深色主题，多线程扫描调度）
- `test_detection.py` —— 检测逻辑单元测试（构造正/反样本，23 个用例 + 10 个容器嗅探用例）
- `test_scan_multithread.py` —— 多线程扫描端到端验证（结果正确性 / 收尾 / 参数裁剪）
- `test_e2e.py` —— 旧版 Web 架构的端到端测试（仅供参考）
- `build.bat` —— 一键打包脚本

（旧版 Web 架构源码 `server.py` + `index.html` 仅保留在本地，未纳入本仓库。）

## 环境要求（重新打包时）

- Windows 10/11，Python 3.10+（仅标准库，无第三方依赖）
- `pip install pyinstaller` 后运行 `build.bat`

验证：`python test_detection.py` 应显示 23/23 通过（另嗅探 10/10）。
